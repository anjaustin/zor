# TriX - Frozen Shape Foundry

**Type a function. Get hardware.**

```bash
pip install trix
trix
```

```
trix> demo
```

That's it. Function becomes polynomial becomes validation becomes code becomes execution.

## What Is This?

TriX compiles pure functions into frozen geometric shapes that execute at silicon speed.

```
lambda a, b: a ^ b  →  polynomial: a + b - 2ab  →  C/CUDA/Verilog
```

No parameters. No training. Just geometry.

## Built-in Shapes

| Shape | Polynomial | Description |
|-------|------------|-------------|
| xor | a + b - 2ab | Exclusive OR |
| and | ab | Logical AND |
| or | a + b - ab | Logical OR |
| not | 1 - a | Logical NOT |
| add | (a + b) mod 256 | 8-bit addition |
| sub | (a - b) mod 256 | 8-bit subtraction |
| mul | (a * b) mod 256 | 8-bit multiplication |

## The Guarantee

**100% validation or no export.**

Every shape is exhaustively validated against its truth table before export. If validation passes, the export is correct by construction.

## Philosophy

- **Geometry is computation.** The polynomial IS the function.
- **Shapes are frozen.** No parameters. No training. Just math.
- **Validation is truth.** 65,536 cases. All must pass.
