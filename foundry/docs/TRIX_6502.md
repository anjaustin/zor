# TriX 6502 - Pure Geometric CPU

The TriX 6502 is a complete MOS 6502 CPU implemented as frozen polynomial geometry.
No neural network. No inference. Just math.

## Overview

The 6502 was the heart of the Apple II, Commodore 64, and NES. The TriX version
implements the same instruction set using pure polynomial computation - the same
mathematics that defines geometry itself.

## Architecture: Three Levels

### Level 0: Polynomial Primitives

All computation reduces to polynomials over normalized inputs (0.0 to 1.0):

| Operation | Polynomial |
|-----------|------------|
| XOR(a,b)  | `a + b - 2ab` |
| AND(a,b)  | `ab` |
| OR(a,b)   | `a + b - ab` |
| NOT(a)    | `1 - a` |

These are the atoms. Everything else is built from them.

### Level 1: Frozen Shapes

16 shapes compose the primitives into useful operations:

| Shape ID | Name | Description |
|----------|------|-------------|
| 0 | `ripple_add` | 8-bit addition with carry propagation |
| 1 | `ripple_sub` | 8-bit subtraction with borrow |
| 2 | `shift_left` | Arithmetic shift left |
| 3 | `shift_right` | Logical shift right |
| 4 | `rotate_left` | Rotate left through carry |
| 5 | `rotate_right` | Rotate right through carry |
| 6 | `parallel_and` | Bitwise AND (8 bits parallel) |
| 7 | `parallel_or` | Bitwise OR |
| 8 | `parallel_xor` | Bitwise XOR |
| 9 | `comparator` | Compare two bytes, set flags |
| 10 | `increment` | Add 1 |
| 11 | `decrement` | Subtract 1 |
| 12 | `bit_test` | Test bits with mask |
| 13 | `nop` | No operation |
| 14 | `transfer` | Copy value between registers |
| 15 | `load_store` | Memory access |

### Level 2: Meaning Layer

Static routing tables map opcodes to shapes:

```c
static const uint8_t SHAPE_TABLE[256];     // opcode → shape_id
static const uint8_t INPUT_A_TABLE[256];   // opcode → source register A
static const uint8_t INPUT_B_TABLE[256];   // opcode → source register B
static const uint8_t OUTPUT_TABLE[256];    // opcode → destination register
static const uint8_t USES_CARRY_TABLE[256]; // opcode → carry participation
static const uint8_t FLAGS_TABLE[256];     // opcode → which flags to update
static const uint8_t ADDR_MODE_TABLE[256]; // opcode → addressing mode
```

The execution loop is trivial:
1. Read opcode
2. Resolve operand (using ADDR_MODE_TABLE)
3. Look up shape and routing
4. Execute frozen polynomial
5. Write result to destination

## Usage

### Export to C

```python
from foundry.export.trix_6502 import TriX6502Exporter
from pathlib import Path

# Export to directory
header, source = TriX6502Exporter.export(Path("./my_6502"))
# Creates: my_6502/trix_6502.h, my_6502/trix_6502.c
```

### Compile

```bash
gcc -O2 -c trix_6502.c -o trix_6502.o
```

### Use in Your Code

```c
#include "trix_6502.h"

// Memory callbacks
uint8_t mem_read(uint16_t addr, void *ctx) {
    uint8_t *mem = (uint8_t*)ctx;
    return mem[addr];
}

void mem_write(uint16_t addr, uint8_t val, void *ctx) {
    uint8_t *mem = (uint8_t*)ctx;
    mem[addr] = val;
}

int main() {
    uint8_t memory[65536];
    trix_6502_t cpu;

    // Initialize
    trix_6502_init(&cpu);
    cpu.read = mem_read;
    cpu.write = mem_write;
    cpu.ctx = memory;

    // Load your ROM at 0x8000
    // Set reset vector at 0xFFFC/0xFFFD

    // Reset and run
    trix_6502_reset(&cpu);

    while (1) {
        trix_6502_step(&cpu);
    }
}
```

## API Reference

### Types

```c
typedef struct {
    /* Registers */
    uint8_t a;      /* Accumulator */
    uint8_t x;      /* X index */
    uint8_t y;      /* Y index */
    uint8_t sp;     /* Stack pointer */
    uint16_t pc;    /* Program counter */

    /* Status flags: NV-BDIZC */
    uint8_t n : 1;  /* Negative */
    uint8_t v : 1;  /* Overflow */
    uint8_t b : 1;  /* Break */
    uint8_t d : 1;  /* Decimal */
    uint8_t i : 1;  /* Interrupt disable */
    uint8_t z : 1;  /* Zero */
    uint8_t c : 1;  /* Carry */

    /* Memory interface */
    uint8_t (*read)(uint16_t addr, void *ctx);
    void (*write)(uint16_t addr, uint8_t val, void *ctx);
    void *ctx;

    /* Cycle counter */
    uint64_t cycles;
} trix_6502_t;
```

### Functions

| Function | Description |
|----------|-------------|
| `trix_6502_init(cpu)` | Initialize CPU to default state |
| `trix_6502_reset(cpu)` | Reset CPU, read PC from 0xFFFC/0xFFFD |
| `trix_6502_step(cpu)` | Execute one instruction, return cycles used |
| `trix_6502_run(cpu, cycles)` | Execute until cycle count reached |
| `trix_6502_irq(cpu)` | Trigger IRQ interrupt |
| `trix_6502_nmi(cpu)` | Trigger NMI interrupt |
| `trix_6502_get_status(cpu)` | Get status register as byte |
| `trix_6502_set_status(cpu, s)` | Set status register from byte |

## Addressing Modes

All 13 6502 addressing modes are supported:

| Mode | Example | Description |
|------|---------|-------------|
| Implied | `INX` | No operand |
| Accumulator | `ASL A` | Operates on A register |
| Immediate | `LDA #$42` | 8-bit constant |
| Zero Page | `LDA $42` | 8-bit address |
| Zero Page,X | `LDA $42,X` | Zero page + X |
| Zero Page,Y | `LDX $42,Y` | Zero page + Y |
| Absolute | `LDA $1234` | 16-bit address |
| Absolute,X | `LDA $1234,X` | Absolute + X |
| Absolute,Y | `LDA $1234,Y` | Absolute + Y |
| (Indirect,X) | `LDA ($42,X)` | Indexed indirect |
| (Indirect),Y | `LDA ($42),Y` | Indirect indexed |
| Relative | `BNE $10` | PC + signed offset |
| Indirect | `JMP ($1234)` | For JMP only |

## What Makes This Special

This is **not** a software emulator. It's not interpreting opcodes.

Each instruction is a frozen geometric transformation - the same mathematics
that describes how a sphere transforms when you rotate it. The CPU is just
polynomial evaluation over lookup tables.

No neural network is involved at runtime. The geometry was discovered through
training, then frozen into pure math. What remains is deterministic, exact,
and fast.
