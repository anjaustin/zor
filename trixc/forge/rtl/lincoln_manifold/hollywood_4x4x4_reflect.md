### 1D: Total Order

```
[A] ←→ [B] ←→ [C] ←→ [D]
```

In 1D, each element has exactly 2 neighbors (or 1 at edges).
The only possible structure is a LINE.
The only possible relation is BEFORE/AFTER.
The emergent behavior: SORTING (imposing total order).


The emergent behavior: CONSTRAINT PROPAGATION.

Think: Sudoku solving. Each cell must agree with its row, column, box.
The "sorting" analogy doesn't hold anymore. We're not ordering - we're SATISFYING.

## Reflection: Why Can't We Predict 4x4x4?

This is Node 11's tension, and it cuts deep.

### The Reductionist Illusion

We want to say: "3D = 2D + 2D + 2D, just stacked."
But this is wrong. Just as 2D ≠ 1D + 1D.

In 1D, a node's "world" is its two neighbors. Simple.
In 2D, a node's "world" is four neighbors arranged in a PLANE. More complex.
In 3D, a node's "world" is six neighbors arranged in SPACE. Qualitatively different.

**The non-linear insight:** Each dimension doesn't ADD complexity.
It MULTIPLIES it. The interaction space grows geometrically.

### Why Prediction Fails

In 1D, I can trace by hand what happens in each cycle.
In 2D, the state space is already 256^16 = 10^38.
In 3D, the state space is 256^64 = 10^154.

**We cannot predict. We can only observe.**

This is not a bug. This is the nature of physics.
We don't predict weather by simulating every molecule.
We observe, measure, build intuition.

The 4x4x4 is a weather system. We'll need to run it and watch.
