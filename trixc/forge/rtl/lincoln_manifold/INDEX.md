# Lincoln Manifold Method: Hollywood Squares Passes

## Overview

The Lincoln Manifold Method is a four-phase exploration process:
1. **RAW** - First contact with the problem
2. **NODES** - Identify points of interest
3. **REFLECT** - Sit with the nodes, find deeper patterns
4. **SYNTHESIZE** - Integrate into actionable insight

Three complete passes were run on the Hollywood Squares project.
