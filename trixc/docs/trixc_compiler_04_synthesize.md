# Synthesis: TRIXC ONNX → Executable Pipeline

## Architecture

Extend `onnx2trix.py` with full C code generation:

```
model.onnx
    │
    ▼
┌─────────────────────┐
│   onnx2trix.py      │
│                     │
│  --emit-c model.c   │
└─────────────────────┘
    │
    ▼
model.c (self-contained)
    │
    ▼
┌─────────────────────┐
│   gcc -O3 -lm       │
└─────────────────────┘
    │
    ▼
model (executable)
```

---

## Key Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Compiler language | Python | Extend existing onnx2trix.py |
| Output format | Single .c file | Simplest to compile |
| Weight storage | Embedded static const | Self-contained binary |
| Buffer allocation | alloca() | Fast, auto-cleanup |
| Dimension handling | Fixed #defines | User can edit and recompile |
| Broadcasting | Error, not supported | Deferred complexity |

## Generated Code Template

```c
/* {model_name}.c
 * Generated by trixc from {onnx_file}
 *
 * Compile: gcc -O3 {model_name}.c -o {model_name} -lm
 */

#include "trixc/onnx_shapes.h"
#include <stdio.h>
#include <stdlib.h>
#include <alloca.h>

/* ═══════════════════════════════════════════════════════════════════════════
 * Configuration
 * ═══════════════════════════════════════════════════════════════════════════ */

{dimension_defines}

/* ═══════════════════════════════════════════════════════════════════════════
 * Weights (static const - goes in .rodata)
 * ═══════════════════════════════════════════════════════════════════════════ */

{weight_declarations}

/* ═══════════════════════════════════════════════════════════════════════════
 * Forward Pass
 * ═══════════════════════════════════════════════════════════════════════════ */

void {model_name}_forward(
    {input_params},
    {output_params}
) {
    /* Intermediate buffers */
{buffer_declarations}

    /* Computation graph */
{shape_calls}
}

/* ═══════════════════════════════════════════════════════════════════════════
 * Main (standalone mode)
 * ═══════════════════════════════════════════════════════════════════════════ */

#ifdef TRIXC_STANDALONE

int main(int argc, char** argv) {
    /* Allocate I/O */
{io_allocation}

    /* Read input */
    if (argc > 1) {
        FILE* f = fopen(argv[1], "rb");
        if (!f) { perror("fopen"); return 1; }
        fread({input_var}, sizeof(float), {input_size}, f);
        fclose(f);
    } else {
        fread({input_var}, sizeof(float), {input_size}, stdin);
    }

    /* Run model */
    {model_name}_forward({forward_args});

    /* Write output */
    if (argc > 2) {
        FILE* f = fopen(argv[2], "wb");
        if (!f) { perror("fopen"); return 1; }
        fwrite({output_var}, sizeof(float), {output_size}, f);
        fclose(f);
    } else {
        fwrite({output_var}, sizeof(float), {output_size}, stdout);
    }

    return 0;
}

#endif /* TRIXC_STANDALONE */
```

    pass

## Implementation Order

1. **`emit_weights()`** - Static const arrays from JSON
2. **`emit_dimensions()`** - #defines from shape info
3. **`emit_shape_call()`** - Template for each op
4. **`emit_forward()`** - Chain shape calls
5. **`emit_main()`** - I/O handling
6. **`generate_c_code()`** - Assemble template
7. **CLI integration** - `--emit-c` flag
8. **Tests** - Unit and integration
