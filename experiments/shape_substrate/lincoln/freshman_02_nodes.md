# Nodes: Freshman Onboarding

## Node 1: The Hook Problem

The first file must deliver "wait, what?" in under 10 lines of code.
No setup. No explanation. Just run → surprise.

Current 01_wait_what.py does this, but then ruins it with explanation.

---

## Node 2: Show Don't Tell

Every line of prose is a liability.
Code that runs > text that explains.

Tension: Some explanation is needed.
Resolution: Put explanation in comments AFTER the surprise, not before.

---

## Node 3: The Challenge Gap

Current files end with "Next: python XX.py"
Should end with "CHALLENGE: Can you make it do X?"

The challenge makes them THINK, not just run.

---

## Node 4: The Modification Prompt

Freshmen learn by breaking things.
Every file should have: "# TRY: Change this value and run again"

Let them discover the edges themselves.

---

## Node 5: The Build Moment

03_build_something.py is the strongest file because it BUILDS something real.
Need more of this. Fewer concept files, more build files.

---

## Node 6: The Leap to Proteins

Files 01-07 are about math.
Files 08-10 suddenly introduce biology.

This is a leap. Need a bridge.

---

## Node 7: The "Show Your Friend" Test

A good tutorial produces something you want to show someone.
"Hey look, I built an 8-bit adder with just +, -, *"

Current files don't have enough of these moments.

---

## Node 8: Self-Assessment

How does the freshman know they understand?
Need: "You got it when you can explain WHY X works"

Not a quiz. A self-check.

---

## Node 9: Depth vs Breadth

Current: 10 files, shallow
Better: 5 files, deep with challenges

Each file should take 15-20 minutes, not 2 minutes.

---

## Node 10: The Skeptic's Escape Hatch

Skeptical freshman thinks "this is BS" at some point.
Need: A place where they can TRY to break it and fail.

"If you think this is a trick, try X. It still works."

---

## Tensions

| Tension | Resolution |
|---------|------------|
| Explain vs Discover | Discover first, explain in comments after |
| Breadth vs Depth | Fewer files, more challenges |
| Passive vs Active | Every file has TRY and CHALLENGE sections |
| Math vs Biology | Bridge file before proteins |
