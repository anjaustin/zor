# Shape Substrate Curriculum

**6 files. 2.5 hours. Zero lectures.**

```
python discover.py   # 15 min - XOR from math (the hook)
python build.py      # 25 min - Build an 8-bit adder
python compose.py    # 20 min - Shapes snap together
python route.py      # 20 min - Inputs find shapes
python system.py     # 30 min - Train and run the whole thing
python life.py       # 20 min - The biology connection
```

## Rules

1. **Run first, read second.** Each file does something before explaining.
2. **TRY sections are not optional.** Modify code. Break things. See what happens.
3. **CHALLENGE sections have hidden solutions.** Try first. Really try.
4. **No skipping.** Each file builds on the last.

## You got it when...

| File | You understand when... |
|------|----------------------|
| discover.py | You can explain XOR = a + b - 2ab on a napkin |
| build.py | You've built a working adder and added to it |
| compose.py | You can build any boolean function from pieces |
| route.py | You can predict which shape wins before running |
| system.py | You've added your own shape and trained routing for it |

## What you'll build

- A polynomial XOR that works like the real thing
- An 8-bit adder from scratch
- A 4-to-1 multiplexer
- A trainable routing system
- Your own custom shape
